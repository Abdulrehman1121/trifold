# Elementor Custom Widgets Guide — Trifold v1.0.0

The `trifold-core` plugin registers 10 bespoke Elementor widgets under the **Trifold Agency Elements** category.

---

## 1. Registered Widgets

1. **Trifold Hero** (`trifold_hero`):
   * Unfolding 3-plane isometric mark ceremony.
   * Controls: Kicker text, headline, sub-headline, primary and secondary CTA buttons.
2. **Unfolding Story** (`trifold_story`):
   * Continuous pinned 4-phase transformation (`Genesis`, `Form`, `System`, `Connected`).
   * Controls: Step numbers, step titles, narrative descriptions, interactive morph canvas.
3. **Cinematic Portfolio** (`trifold_carousel`):
   * Horizontal draggable showcase (~75vw centered stage with adjacent peek).
   * Controls: Featured-only toggle, project count, speed, cursor label.
4. **Services Experience** (`trifold_services`):
   * Interactive unfolding discipline rows (01 Brand Identity, 02 Websites, 03 Graphic Design).
   * Controls: Category filters, pillar ordering, sub-service list toggles.
5. **Philosophy Typography** (`trifold_philosophy`):
   * Monumental typographic manifesto with vermilion emphasis.
   * Controls: Heading text, subtitle, button link.
6. **Process Sequence** (`trifold_process`):
   * 6-phase discovery-to-launch workflow.
   * Controls: Phase titles, deliverables, phase descriptions.
7. **Graphic Design Wall** (`trifold_graphic_wall`):
   * High-fashion editorial masonry layout.
   * Controls: Image columns, concept project badges, spacing.
8. **Trifold CTA** (`trifold_cta`):
   * Conversion crescendo banner ("Good things unfold").
   * Controls: Background surface, button targets, contact email link.
9. **Project Gallery** (`trifold_gallery`):
   * Multi-image case study showcase with lightbox support.
10. **Animated Heading** (`trifold_heading`):
    * Kicker tag, fluid Manrope display headline, and optional divider line.

---

## 2. Using Widgets in Elementor

1. Open any page in the **Elementor** editor.
2. Scroll to the **Trifold Agency Elements** section in the left panel.
3. Drag any widget onto the page canvas.
4. Customize settings in the **Content**, **Style**, and **Advanced** tabs.
5. All widgets utilize global Trifold CSS variables (`--color-ivory`, `--color-ink`, `--color-vermilion`, `--color-stone`) for instant brand consistency.
